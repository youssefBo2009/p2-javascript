Onderzoek JavaScript

Wat is het verschil met de script tag boven in te laden in de head tag ten opzichte van onderaan in je HTML?

Als je de script tag boven in de head zet, wordt JavaScript geladen voordat de browser klaar is met het lezen van de HTML. Hierdoor kan de website langzamer laden.

Als je de script tag onderaan de body zet, wordt eerst de HTML geladen en daarna JavaScript. Hierdoor kan de inhoud van de website eerst verschijnen.

Wat doet het attribuut defer in de script tag?

Het attribuut defer zorgt ervoor dat JavaScript alvast wordt gedownload, maar pas wordt uitgevoerd wanneer de HTML helemaal is ingelezen. Hierdoor hoeft de browser niet te wachten met het laden van de website.

Wat is het verschil tussen HTML en JavaScript?

HTML gebruik je om de structuur en inhoud van een website te maken, zoals teksten, afbeeldingen en knoppen.

JavaScript gebruik je om een website interactief te maken, bijvoorbeeld door een knop iets te laten doen wanneer je erop klikt.

Wat is het verschil tussen innerHTML en innerText?

innerHTML gebruik je om HTML-code of tekst in een element te plaatsen. Je kunt hiermee bijvoorbeeld ook een kopje of een link toevoegen.

innerText gebruik je om alleen gewone tekst in een element te plaatsen. HTML-code wordt hierbij niet als HTML uitgevoerd.
